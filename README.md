🏛️ Historical Wonders - Beginner
A beginner-friendly web project showcasing some of the most iconic historical wonders from around the world. Ideal for practicing HTML, CSS, and basic JavaScript while learning about global heritage sites.

🌍 Project Highlights
Displays a list of famous historical wonders
Includes images, brief descriptions, and locations
Clean and beginner-friendly layout
Fully responsive design

🛠️ Tech Stack
HTML
CSS
JavaScript (optional for interaction)

📦 How to Run
Clone the repository:
git clone https://github.com/vickykuthe/Historical-wonders-Beginner.git
Open the index.html file in your browser
